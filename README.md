# Finger Window

Vite + React + TypeScriptで作る、両手の指先に追従するカメラエフェクト。
MediaPipe Hand Landmarkerで指の位置を検出し、Canvas 2DとWebGLで映像を合成します。

## 開発

Node.js 22.12以上を使ってください。

```sh
npm ci
npm run dev
```

開発URLは `http://127.0.0.1:4173`。カメラの開始にはブラウザの許可が必要です。

```sh
npm run typecheck
npm run build
npm run preview
```

`dist/`はViteが生成する公開用ファイルです。編集は`src/`で行います。
依存バージョンは`package-lock.json`で固定されています。

## 構成

- `src/components/`: カメラ画面・設定パネル。Reactは低頻度の表示状態を管理。
- `src/hooks/`: Reactとカメラセッションの接続、任意のWebMCP登録。
- `src/camera/CameraSource.ts`: カメラ権限・ストリーム・停止処理。
- `src/camera/CameraSession.ts`: セッションとフレームループ。座標はReact stateに入れません。
- `src/tracking/HandTracker.ts`: モデルの遅延読み込み・GPU/CPU切替・座標の平滑化。
- `src/rendering/`: 枠、手の関節、映像加工、WebGLリソースの解放。
- `src/lib/geometry.ts`: 凸包、面積、サーモ色の計算。
- `src/types.ts`: 型と初期設定。

## 実行条件

カメラはHTTPSまたはlocalhostで利用できます。初回にWASMをjsDelivrから、
モデルをGoogleの配布元から取得するためインターネット接続が必要です。
映像の検出・加工と任意の録画はブラウザ内で行い、映像送信はしません。
両手が検出されたときだけ加工窓を表示します。サーモは疑似的な色変換です。
停止・画面離脱でカメラのトラックを解放し、アンマウントでモデルと描画リソースも解放します。

## 写真・動画の窓

「写真・動画を選ぶ」でローカルファイルを読み込み、4点の凸四角形へ透視変形して表示します。
ファイルはブラウザのObject URLで読み込み、サーバーへ送信しません。
`useWindowMedia`が読み込みの取消、動画再生、URL解放を管理し、`MediaWarp`が描画を担当します。
動画は音声付き・ループ再生で、カメラ停止時に一時停止します。音声のオン・オフを切り替えられ、自動再生が制限された場合は音声オフで再生します。対応形式はブラウザのデコーダーによります。
メディア表示中は元の写真・動画を表示し、カメラエフェクト用のつまみ・強さ操作を適用しません。
「カメラエフェクトに戻る」で元の操作へ戻れます。

## 公開設定

`.openai/hosting.json`に既存Sitesの識別子と`dist`の静的配信設定を保存しています。
Sitesの公開処理では`npm run build`の出力を配信します。


## 録画・保存

CanvasRecorderは表示用Canvasを30fpsで録画し、対応形式を実行時に選択します。動画音声はWeb Audioで合成し、ミュート・音量操作を反映します。マイクは使用しません。録画停止後のプレビュー、ダウンロード、対応端末のWeb Shareによるファイル保存を提供します。
録画は3分または80MiBで停止します。カメラ停止・背景移動時にも終了し、録画用トラックとObject URLを解放します。ファイルはサーバーへ送信しません。スマホ実機の対応はOS・ブラウザの録画/共有APIによります。


## 花の軌跡

花の軌跡モードでは人差し指の移動距離ごとに6種類の花を順番に描画します。花は端末の絵文字フォントで表示するため見た目が環境で変わります。永続レイヤーへ描き込むため、経過時間による消去や描画オブジェクト数の増加によるメモリ増加はありません。カメラ停止・モード切替でも保持し、ページ再読み込み時にリセットします。
MediaPipeの左右情報は未反転入力に合わせて補正し、右手の4本の指が曲がった状態を400ms検出すると全消去します。鏡表示の設定には依存しません。花を消すボタンも利用できます。

## 写真撮影

4つの指先が一定以上の大きさの四角い枠を450ms保つと3秒カウントダウンを開始し、描画直後のCanvasをJPEGへコピーします。数字などDOMの表示は写真に入りません。枠が300ms以上崩れたら中止し、600ms指を離すまで再撮影しません。カメラ停止・背景移動・自動撮影オフでも中止します。写真のプレビュー、ダウンロード、対応端末のファイル共有を提供し、画像は端末内で処理します。
